# PLC IO Check Helper — 공식 안내 저장소

**PLC IO Check Helper**는 Mitsubishi MELSEC PLC의 입출력(I/O) 상태를 현장에서 빠르게 점검·모니터링하는 Android 앱입니다.
PC나 전용 장비 없이 스마트폰만으로 PLC에 직접 이더넷 접속해 디바이스 값을 실시간으로 읽습니다.

이 저장소는 앱의 **공식 안내**(제품 정보·다운로드 경로·가이드 링크)를 관리합니다.

## 주요 기능

- **IO 체크(입출력 점검)** — 등록한 X·Y 입출력을 현장에서 OK/NG로 점검(수동·자동·안내형 순차 3모드). 배선 맞바꿈·단락을 자동 적발하고 결과를 CSV·요약 리포트로 공유
- **이더넷 직접 통신** — MC Protocol·SLMP, TCP/UDP, 3E/4E Frame, Binary/ASCII
- **비트 디바이스 모니터링** — X/Y/M/L/B 등의 ON/OFF 상태
- **워드 디바이스 읽기** — D/W/ZR 등 (10진/16진, 부호·32비트·실수·문자열 표시)
- **무제한 디바이스 등록** — 자동 폴링·수동 새로고침, 동시 모니터링 개수 제한 없음
- **자동 등록** — 선두 주소·증가 간격·수량으로 디바이스 시퀀스 일괄 생성
- **계층형 그룹 관리** — 접기/펼치기·드래그 재정렬·그룹 통째 삭제, 그룹·검색·상태별 필터
- **배치 모니터** — 디바이스·어드레스를 직접 입력해 여러 값을 표로 즉석 일괄 조회
- **IO 모아보기** — 입력·출력 신호를 구분한 카드로 디바이스 I/O를 한눈에 시각화
- **프로젝트 저장·공유** — 여러 프로젝트를 `.plc` 파일로 내보내 기기 간 이동
- **GX Works 가져오기** — GX Works2 프로젝트(`.gxw`)를 직접 열거나 코멘트/래더 CSV로 디바이스 일괄 등록(코멘트 복구·디바이스 종류별/POU별 자동 그룹 분리·POU 트리 미리보기·더블코일 경고)
- **GX Works 통신 설정 인앱 가이드** — 연결 설정 화면 도움말에서 PLC 파라미터 설정 절차 안내
- **다국어·테마** — 한국어 / English / 日本語, 다크·라이트

## 안전 및 면책

이 앱은 **읽기 전용(모니터링)** 입니다. 설비를 변경하지 않습니다.

본 앱은 Mitsubishi Electric Corporation과 무관한 독립 서드파티 앱이며, 어떠한 제휴·보증·승인 관계도 없습니다. MELSEC, GX Works 및 관련 명칭은 각 권리자의 상표이며 호환성 표시 목적으로만 사용됩니다.

GX Works2(`.gxw`) 가져오기는 사용자가 보유한 파일에서 디바이스·코멘트를 추출하는 호환 편의 기능입니다. 추출 결과는 참고용이며 일부 디바이스·코멘트가 누락되거나 다르게 해석될 수 있으니 현장 적용 전 반드시 확인하십시오. 정확한 전체 데이터가 필요하면 GX Works2에서 코멘트 CSV로 내보내 가져오는 방법을 권장합니다. 암호(보안 설정)가 걸린 파일은 열지 않습니다.
